Workflow

How It Works

Three simple steps from application to certified document.

1

Citizen Registers Online

Fill in child, parent, and location details. Upload supporting documents and photos.

2

Woreda Registrar Reviews

The admin reviews the submission through the dashboard and approves or rejects with a reason.

3

Certificate Issued

An official printable certificate is generated with a unique QR code for instant verification.

Capabilities

Everything You Need

Built for citizens and registrars alike, with security at every layer.

📝

4-Section Birth Form

Structured form covering Child Info, Parents, Location, and Applicant details — with file upload previews.

📋

Real-time Status Tracking

Citizens see a live dashboard showing their registrations as Pending, Approved, or Rejected.

📄

QR-Verified Certificates

Approved applications generate downloadable certificates with embedded QR codes for instant authenticity checks.

🏛️

Rich Admin Panel

Jazzmin-powered Django admin with bulk approve/reject, CSV export, date hierarchy, and photo thumbnails.

🌐

Fully Bilingual

Every screen — forms, labels, certificates, error messages — displayed in both Amharic and English simultaneously.

🔒

Multi-Layer Security

Admin routes return HTTP 404 to regular users, CSRF on all forms, PBKDF2 password hashing, and session flushing on logout.

📅

Ethiopian Calendar Support

Built-in EC→GC conversion and Pagumē (month 13) validation — fully aware of the Ethiopian civil calendar.

🌙

Dark / Light Mode

Persistent theme preference stored per session, available on every page of the portal.

User Roles

Two Roles, Clear Boundaries

Access is enforced at every layer — from the view decorator to the database.

👤 Citizen (User)

  • Create an account via the public registration page
  • Submit birth registration applications
  • Upload child photos and hospital documents
  • Track application status in real time
  • Download approved QR-verified certificates

🏛️ Registrar (Admin)

  • Access the secure Jazzmin admin panel
  • Bulk approve or reject registrations
  • Search by child name, parent, phone, or ID
  • Export filtered records to CSV
  • Print official certificates directly from admin

Quick Start

Up and Running in Minutes

Clone, install, migrate, and go.

01

Clone & Install

Clone the repo and install dependencies.

git clone <repo-url>
pip install -r requirements.txt
02

Migrate Database

Apply all migrations to set up the schema.

python manage.py migrate
03

Create Admin

Use the management command to create the registrar account.

python manage.py create_admin
04

Run Server

Start the development server and open your browser.

python manage.py runserver
